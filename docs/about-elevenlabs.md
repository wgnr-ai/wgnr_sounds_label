# ElevenLabs — Explainer Copy

## The One-Paragraph Version
ElevenLabs is an AI research company focused entirely on audio. They build and train their own audio models — the kind that turn text into speech, transcribe speech back into text, change one voice into another, and generate music. Every product they offer is built on those same in-house models.

## What ElevenLabs Is
- AI research company, audio-specialized
- All models trained in-house — each purpose-built for a specific task
- The models are the foundation; everything else is built on top of them

## Three Ways to Use It
1. **ElevenLabs Creative** — a no-code app for creators
2. **ElevenLabs Agents** — build voice agents, either from a dashboard or in code
3. **ElevenLabs API** — the raw models, for building anything yourself

## Core Capabilities

**Text to Speech.** Call convert, pass in text, get back audio. Two models cover the two priorities: one tuned for expressive delivery, one built for speed when latency matters. Pick from **10,000+ voices across 70+ languages**.

**Speech to Text (Scribe).** The same idea in reverse — send audio, get a transcript. Handles **90+ languages**, with a real-time version that transcribes while someone is still talking.

**Everything else, through the same client:**
- Voice conversion — change one voice into another
- Sound effect generation
- Music generation (ElevenLabs Music)
- Video dubbing into another language
- Background noise removal
- Voice agent creation (ElevenLabs Agents)

## For Developers
One server-side package. Drop in your API key. That single client calls every model — no separate setup per feature. The docs are the place to start.
